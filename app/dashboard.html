About LibreDisplay

LibreDisplay · by Gubna
Your home. Your dashboard. Your data.
Free and open-source self-hosted home dashboard.
Release 1.6.2 · Theme system: Libre Night · MIT License

Displays

One LibreDisplay server can power multiple screens. Each named display has its own calendars, photos, layout, theme, and read-only Display Link. Use a lightweight Viewer, tablet, TV browser, or another Pi at each screen.

Remote management

Use the admin pairing link for configuration. Every named display has its own read-only Display Link; the field below shows the link for the display you are currently editing. Both are limited to your trusted LAN/private VPN. Do not port-forward LibreDisplay directly to the public internet.
Remote editing is off by default. Enable it here only when you want to pair another device.

Local accounts & roles

Create local Owner, Editor, or Viewer accounts. Owners administer the whole server. Editors can change only their assigned displays. Viewers can open only their assigned displays and cannot save configuration. Passwords are stored locally as PBKDF2-SHA256 hashes.

Display profiles

Save complete dashboard configurations as named profiles, then reuse them on this display or explicitly apply them to another LibreDisplay endpoint. Profiles are snapshots of dashboard content and presentation; applying one never changes the profile itself. Use “Update selected” only when you intentionally want to replace a profile with the currently saved dashboard.
Tip: duplicate a known-good profile before experimenting. Profiles can also be used by Scenes & schedules below.

Scenes & schedules

Schedule saved Profiles on this display. LibreDisplay applies scenes on the server, so schedules continue working even when no Settings browser is open. Overnight ranges are supported.

Family & touch mode

Local-only household chores, points, rewards, and child-lock controls. Add a Family Chores block from Arrange dashboard to make these touch-friendly on a wall display. No cloud account is required.
PIN / child lock
When enabled, completing chores and redeeming rewards from a display requires the household PIN. The PIN is stored as a salted PBKDF2 hash, not plaintext.

Location & Weather

Search for a place, then choose the exact match before saving. LibreDisplay shows the region, country, coordinates, and timezone so cities with the same name are not confused. Forecast values come from the weather model/grid for those coordinates and can differ somewhat from a nearby personal weather station.
Shown above Current Weather on the dashboard. Leave blank to hide the label; it does not change the selected forecast coordinates.

Calendars

Add as many calendars as you need. LibreDisplay accepts standard iCalendar/ICS subscription links from Google Calendar, Proton Calendar, Outlook/Microsoft 365, iCloud shared calendars, Nextcloud, Fastmail, and other providers that expose an ICS feed. You can also import a local .ics file.
Add only the feeds you use. Each can be renamed, checked, colored, reordered, disabled, duplicated, or removed.
Calendar preferences
Opacity affects events from that feed only. Display priority is used for the legend and as a tie-breaker when events start at the same time.

Weather alerts

Uses active National Weather Service alerts for the configured location (U.S.). Up to 10 alerts are shown. Test mode generates 10 simulated alerts locally so you can tune the layout at any time.

Pictures & backgrounds

Choose the picture source and tune its rotation in one place. Use Google Photos, built-in stock categories, local folders, mounted NAS/network folders, or no photo background.
Stock backgrounds use the external SourceSplash image service and require internet access. The service may source images from multiple licensed providers.
Google Photos shared album
Google Photos → open album → Share icon → “Create link” → copy URL. LibreDisplay paginates large shared albums and loads up to 1,000 photos per album.

Weather Details element

Build the Weather Details element row-by-row. Enable only the metrics you want, then drag rows or use the arrow buttons to change their display order. Air Quality and UV use the same cached Open-Meteo air-quality source as the optional Air Quality block.

Background appearance

These controls preview live and only affect how the current background is presented on screen.

Starter templates

Apply a presentation/layout starting point without replacing your calendar links, photo folders, location, integrations, or added custom blocks. The template previews immediately; Save & Apply replaces any saved built-in Arrange positions, while Cancel/Esc restores them.

Theme & typography

Libre Night is the default LibreDisplay look: black and charcoal surfaces with a restrained green accent, designed for an always-on home display. Other included themes keep the same UI structure while changing the mood. Theme and font changes preview live.

Accessibility & language

Keep the everyday controls simple while adapting motion, contrast, keyboard focus, and date language for the people who use this display.
Always-on display care
Optional screen care can lower static brightness after a period without local interaction. It never moves or rewrites your saved layout and wakes instantly when the screen is used.
Reduced motion disables decorative transitions and continuous alert/background animation where possible. It does not stop data refreshes. Screen care is off by default.

Dashboard layout

Choose from LibreDisplay’s expanded layout library. These are original command-center compositions built around the patterns that work best on wall displays: calendar-first, photo-first, split planner, weather-focused, compact, and portrait. Selecting a card stages the layout only for preview; your saved dashboard is untouched until Save & Apply. Use Preview selected layout to inspect it full-screen with your real calendar, weather, background, and added custom blocks. Cancel/Esc restores the saved layout.
Current saved layout selected.
Preset layouts stage the built-in positions, alignment, and content density as one balanced composition. Standard presets leave added blocks exactly where you placed them. Integration Showcase presets also snap compatible configured blocks into their labeled slots so the live preview matches the intended composition; unmatched blocks stay put. Empty showcase slots are preview-only suggestions and are never saved as fake data. Your accounts, data sources, credentials, theme, and background stay intact.
Advanced layout editor
Unlock the dashboard to drag and resize each major element independently. Select any element to open its inspector for content size, font, text color, opacity, horizontal/vertical content alignment, and precise screen placement. Arrow keys nudge a selected block; Shift + arrow resizes it. For added blocks, Delete removes, Ctrl/Cmd+D duplicates, Enter configures, and double-click opens configuration. Press A for Add Block or ? for the shortcut guide. The Add Block catalog supports multiple reusable custom blocks. Positions are stored proportionally so layouts scale across similar screen resolutions.

Update history & rollback

Native updates keep a private pre-update snapshot containing the previous LibreDisplay application plus the sensitive safety backup created at that same point. Rollback verifies the snapshot, keeps your current state recoverable, restores the previous version and its pre-update data, then restarts the device.

Backup & recovery

Create a portable settings bundle for moving LibreDisplay to another device, or keep local restore points before experimenting. Portable bundles include this display's settings plus Profiles and this display's Scene rules, but not media files, account passwords, pairing secrets, or host/NAS credentials.
Portable backup
Best for migrating settings between LibreDisplay installations.
Local restore points
Stored privately on this LibreDisplay host. A restore point captures the current display configuration plus the server-wide Profiles and Scenes stores, so restoring one can affect scheduled profiles used by other displays.
Loading restore points…
Need a full server backup? The existing backup.sh / server-backup.py tools remain the correct path when you also need media, plugins, environment secrets, or host/NAS state. Full backups may contain credentials and should be protected like passwords.
